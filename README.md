# Grocery Tracker and Recommendation Generator

## Project Description
The **Grocery Tracker and Recommendation Generator** is an AI-powered web application designed to help users identify grocery items from uploaded images and manage their grocery list. The application leverages Google’s **Gemini 1.5** generative AI model to process images and extract the names of grocery items. The app also allows users to manually input items, and it provides features for recipe generation and grocery improvement recommendations. It is built using **Streamlit** for the user interface and deployed on **Streamlit Cloud** for easy access.

### Features:
- **Image Recognition**: Upload grocery item images, and the app extracts item names using AI.
- **Manual Input**: Users can also manually enter grocery items.
- **Grocery List Management**: Users can edit, remove, and track quantities of items.
- **AI-Powered Recommendations**: Generate grocery improvement suggestions or recipe ideas based on the current list.
